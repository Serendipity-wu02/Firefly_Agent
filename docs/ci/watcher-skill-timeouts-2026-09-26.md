## 调用链与有依据的修改

### 文件监视夹具

旧夹具在 15 秒测试预算内同步启动 Windows PowerShell、初始化 COM，仅为了取得短路径。此调用没有自身超时且阻塞事件循环；本地分段测量为 701.5 ms，但不能由本机值解释云端 18 秒空档。

改用实际 `ComSpec` 的异步 cmd 内建 `for` 短路径展开（[微软语法说明](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/for)），不启动 PowerShell/COM；设置子进程 5000 ms 上限并传递测试取消信号。先断言短路径与原路径 native realpath 相同，再执行原有真实监听、工作区/外部 HEAD 事件、忽略规则与关闭后无通知断言。15 秒测试上限不增加。增加单条阶段/耗时诊断，未来失败可以区分初始化、挂载、事件、忽略检查和关闭。

### Skills 无需迁移路径

源码确认加载的是仓库 `vendor/firefly-skills/skills-snapshot.zip`，`extract-zip@2.0.1` 只做本地文件 I/O；没有网络、共享解压缓存或锁。归档 231 项，解压后 2727636 字节。原函数无论用户是否安装旧版，都先全量解压、再逐个判断八项旧文件摘要，最后删除整个临时目录。本次失败夹具只有用户修改过的 README，最终无需替换任何文件。

将现有路径防护和摘要核验移到解压前，无匹配就返回；只有确有旧版文件才创建临时目录、解压。解压后仍再次核验路径与摘要，保留并发修改保护、独占备份和 finally 清理。未扩大可迁移文件集合，未修改版本摘要或延长测试时限。

回归明确验证无须迁移时不调用解压；新增匹配后替换与备份、解压期间用户编辑、解压失败清理、根目录逃逸与空安装检查。匹配分支使用公开夹具并显式模拟旧版摘要和解压器，不宣称这是实际旧语料或真实解压服务验证；`replaceUnmodifiedSkill` 原有真实 SHA-256、备份及用户编辑测试保留。

## 共同因素核查

- CI 单 worker、文件串行、每文件独立 fork；两项超时分属不同生命周期，不存在这两项同时执行的证据。全量共有 506 个文件，本地组合只有 2 或 4 个；不能用本地成功证明 CI 资源无争用。
- 诊断脚本没有资源轮询定时器。主进程按 IPC/退出事件同步记录，子进程记录 spawn/exit/close/kill；完整上传记录约 5.28 MB。分段本地运行中主进程 39 次同步追加累计 20.62 ms。
- 最终四文件组合：保留诊断两轮 5.81 s、6.06 s；不加载诊断一轮 5.85 s，全部通过。没有测得足以解释 5/15 秒超时的诊断开销，因此不删除退出取证，也不盲目改 worker、Node 或内存配置。
- Skills 原始超时会让未完成的异步函数继续执行，而测试 afterEach 已开始清理用户夹具；本次无须迁移路径现在在首次异步解压前直接完成。实际需要解压的路径仍 await 解压并在 finally 清理，新测试覆盖成功及失败后的临时目录不存在。未凭此推断历史遗留临时目录数量。
- Windows 监视测试所有退出路径继续 await dispose，cmd 失败/取消/超时不会跳过 finally。未发现共享目录（两条链均 mkdtemp）、共享状态或明确泄漏导致本次两项超时的直接证据。
