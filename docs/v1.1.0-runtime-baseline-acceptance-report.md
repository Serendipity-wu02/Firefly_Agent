## 3. TTS 诊断链路与真实报错表现

```
ChatMessageItem (点击播放语音)
   │
   ▼
TtsPlaybackManager.speak()
   │ [TTS Trace] start: requestId=... chars=...
   ▼
window.tts.startSession (IPC)
   │
   ▼
TtsSessionService -> FireflyTtsDispatcher.synthesize()
   │ [TTS Trace] request: requestId=... behavior=...
   │ [TTS Trace] dispatch: engine=gptsovits / custom-cloud / minimax
   │ [TTS Trace] engine: invoking synthesizer...
   ├── [成功]: 返回 base64 -> [TTS Trace] result: synthesis success -> Audio.play() -> [TTS Trace] playback-start / playback-end
   └── [失败]: 真实抛出错误 -> TtsSessionService 捕获 -> [TTS Trace] playback-error -> 按钮即时渲染 "⚠️ 播放失败"
```
