- **Context Isolation**: `contextIsolation: true` configured on all `BrowserWindow` instances (`Pet`, `Chat`, `Summary`, `Settings`).

- **Sandbox Architecture**: Preload scripts interact only through safe whitelisted IPC channels.
- **Protocol Security**: `assets://` custom protocol registered with explicit privilege isolation and local directory containment.
