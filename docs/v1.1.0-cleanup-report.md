4. **Knowledge Data Boundary**: Confirmed `data/knowledge/` as pre-computed RAG runtime index assets (distinct from canonical markdown/yaml source in `src/main/character/resources/`).
5. **Zero Character / Architecture Deviation**: Persona SSoT, CharacterPolicyEngine, Behavior Runtime, Embodiment, Live2D, RAG, and Music architectures remain 100% frozen and unmodified.

## 3. UserData Migration Architecture

```
[ Electron Main Process ]
         │
         ├── app.getPath("userData")
         │         │
         │         ├── settings.json       (User settings & API configurations)
         │         ├── memory.json         (User long-term memory state)
         │         └── cache/tts/*.wav     (Synthesized audio cache)
         │
         └── app.getAppPath() (Repository Root)
                   │
                   ├── src/settings/settings.example.json   (Static Default Template)
                   ├── src/main/character/resources/       (Persona & SSoT Lore)
                   ├── src/renderer/public/models/         (Live2D Models & Textures)
                   └── data/knowledge/                     (RAG Chunks & Vector Index)
```

### Path Resolution Rules:
- `SettingsManager`: Reads `app.getPath("userData")/settings.json`. If missing, falls back to `src/settings/settings.example.json`.
- `FireflyMemoryService`: Reads/writes `app.getPath("userData")/memory.json` (fallback `os.tmpdir()` for testing).
- `TtsCache`: Caches synthesized audio into `app.getPath("userData")/cache/tts/` (fallback `os.tmpdir()/firefly_cache/tts` for testing).
- `WindowManager`: Reads/writes window placement to `app.getPath("userData")/settings.json`.
