## 范围与现状

- 沿用新底座的 TTS 设置、会话、缓存、播放、取消与工具权限链；没有加入第二套运行循环。
- QQ Music 适配已写入 Main、Preload、设置页和现有工具注册。网易云专用的运行入口、设置页、播放器窗口构建入口及打包组件已停用；旧源码与用户历史数据未批量删除。
- Chat Markdown 的表格、引用框、行内代码与装饰色跟随 Firefly 主题；错误、警告及语法高亮仍按语义着色。

## 语音范围纠正

旧 Firefly 的 `src/shared/tts-types.ts` 定义 `firefly-v2proplus`、GPT-SoVITS V2ProPlus、中文、seed 15、`cut5`、语速 0.9，以及一个示例服务地址和与特定参考音频匹配的文本；参考音频路径为空。新底座复用 `/tts` JSON 协议，采用文件确认的 seed 与分段方式、发音归一化，并将取消信号传到请求与会话终态。音频格式不符时明确失败，取消结果不写入缓存。

`src/main/settings/settings-facade.ts` 的 TTS 默认关闭，GPT 服务地址、参考音频路径和对应文本全部为空。旧项目的地址与示例台词均不作为新底座默认值；用户必须通过现有语音设置选择本机资源并填写准确文本。通用语速设置仍为 1，旧项目的 0.9 可由用户在现有滑块设置，不改变其他语音提供方的全局默认速度。GPT-SoVITS 模型与权重由外部服务加载，本应用不自动选择或携带 V2ProPlus 模型。

语音设置页的提示和新建 MiniMax 音色 ID 不再默认指向昔涟。缺少配置或服务失败时，自动朗读呈现错误状态，不伪装播放完成，也不阻断文字回复。已有用户配置不被覆盖。`README.md` 与 `README.en.md` 明确 Firefly 仓库和安装包不包含外部 GPT-SoVITS 环境、模型、参考音频或缓存。

用户本机 GPT-SoVITS 目录仅作本地联调来源；本轮未复制、导入或提交其中源码、权重、音频和缓存。当前 `electron-builder.yml` 只打包本项目的构建、声明、资源及 QQ 桥脚本，没有引用该目录。项目源码与构建输出中的音频文件仅有原有的两项通知音效，没有 GPT 参考音频或模型权重。没有制作安装包，因此这是打包规则和现有文件检查，不是安装包内容的实测保证。

- `src/main/music/scripts/qqmusic_gsmtc.ps1` 只匹配真实 `QQMusic.exe` 媒体会话；`qqmusic-service.ts` 区分命令提交结果与再次读取的状态变化。播放器不可用、拒绝、取消与错误播放器不会回退到其他 Provider。

- 相关 10 个 Vitest 文件、61 个用例通过；打包规则检查 4 个用例通过。`npm run check:renderer` 与 `npm run build` 通过；`dist/renderer/music` 不存在。`git diff --check` 无空白错误，Git 仅提示现有行尾转换。
