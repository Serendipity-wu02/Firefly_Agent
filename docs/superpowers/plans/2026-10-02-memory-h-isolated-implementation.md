## Binding design

- Trusted Main actor capability supplies ownership. Default current actor/current session/current source provider; Main can mint an explicit session/provider allowlist after actor resolution. Provider is source attribution, never actor identity. Temporary/fake tokens fail. Partition before decryption/candidate generation/BM25 corpus statistics/vector computation/cache/final read; no shared corpus caches. No unauthorized counts or scores.
- Worker decrypts authorized canonical history into a bounded in-memory index. Persist only authenticated encrypted document/derived payloads, never plaintext FTS, terms, vectors, logs or scratch files. Digests bind content but do not encrypt it. Opaque/keyed lookup identifiers follow existing storage boundaries. First version has no persisted index cache.
- Separate BM25 and vector rankings, cap each at 50, reciprocal rank fusion k=60 with equal route weights, then vector MMR lambda=.7 when the entire union has compatible vectors. BM25-only uses lexical term-set duplicate filtering and is explicitly not vector MMR. Result limit 8 and total excerpt character budget 16000; all initial values versioned/configurable and pending representative quality evaluation. Default vector disabled; synthetic local-only injected embedding contract tests only.
- Bind each candidate/result to immutable document digest, incarnation/revision, source bindings (including generation/content revision), derived roots, suppression generation, index/tokenizer/ranking version and authorization partition. Rebuild and source edit/delete/forget interleavings fail closed. Budget preparation captures these deps and the existing worker S send claim transaction rechecks them. No new await between final claim and local send; M usage protocol unchanged.
- Whole attributed document-turn excerpts keep complete assistant tool calls/results together. Historical roles are encoded as quoted evidence in a current user evidence container, never promoted to active system/assistant/tool instructions. Each original message preserves role, original event time/timezone (unknown remains unknown), source session and revision; import time never replaces event time. No neighbor expansion in v1; future expansion must recalculate scope/deps/budget.
- Hard index byte/document limits return `index-budget-exhausted`, no silent deletion. Excerpt budget exhaustion is separately reported. Archived M inspection stays outside automatic H and respects canonical visibility/forget.
- Synthetic export format `firefly-history-synthetic-v1` only. Preview capability is a read-only report ticket; apply requires a separately minted Main apply authorization. Export actor/confirmation/provenance claims cannot mint actor caps or M supports. Imported history has no asserted direct-user trust and is conservatively unavailable after suppression generation changes unless independently re-established through sanctioned canonical provenance. Same source ID/revision/digest idempotent; same ID/revision/different digest quarantined, no last-import-wins. Apply bounded/cancellable/idempotent with immutable digest and generation, no M writes. Conflict metadata and receipts encrypted.
- Additive v8→v9 schema, actual pre-change v8 writer fixture, wrong-key/future/fault byte proof, complete DB/auth/key/profile backup and actual old writer restore. No DROP/reset downgrade.

## Implementation rulings and review focus

- Each query rebuilds a worker-local index, with no persisted/shared query cache or neighbor expansion. Candidate IDs include keyed actor/provider/session partition, avoiding same-locator collisions across explicitly authorized sessions.
- H actor-specific suppression generation reads canonical M ownership/barrier metadata; sanctioned other-actor forget cannot change H counts/ranks. Unowned legacy barriers conservatively use the scope barrier. The existing S/M scope-wide final snapshot barrier remains unchanged: unrelated scope changes can conservatively invalidate an S permit, requiring a new snapshot, without changing H ranking/counts.
- The existing M visible-facts method initializes/updates recall projection. H instead uses a new read-only visibility inspection seam, which does not initialize policy/state or refresh access. Linked canonical M roots and subject keys respect archive, and their visibility revision is bound into H evidence so archive→restore cannot revive old evidence. H quotation is not M actual-use and does not create M usage dependencies/tickets by itself.
- Synthetic export records require original sourceProvider/sourceSession matching the separately authorized Main destination. These are attribution claims, never actor identity/provenance proof. Quoted citations include origin; unknown event time/timezone remain null.
- Retained actual v8 writer bundle/fixture hashes are checked in. Older schema-equivalent tests remove the additional v9 table when manufacturing old-schema fixtures; actual prior-writer tests do not fabricate old schemas.
- Native Jieba is loaded lazily only when an H tokenizer is constructed, so unrelated core worker bundles do not accidentally bundle native optional dependencies. Native H probes include the actual installed Windows addon and unpack its .node file in ASAR.
