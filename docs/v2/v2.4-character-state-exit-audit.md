# Firefly-Agent V2.4: 角色数值状态退出审计报告 (Character State Exit Audit)

- **版本基线**: Firefly-Agent V2.4 (`firefly-v2.4-alpha1`)
- **审计日期**: 2026-09-01
- **架构方向调整**: **正式停止“数值养成型宠物状态（Numeric Pet Stats）”路线**，将角色状态系统由历史电子宠物式数值养成体系（好感度/饱食度/精力值/健康值/注意力/离线衰减/喂食/治疗）全面平稳过渡为 **V2.4 角色认知语义状态（Character Semantic State）**。
- **本阶段性质**: 只读审计与退出矩阵确立，零破坏性删除。

## 2. 状态分类：必须退出 vs 必须保留与重构

```text
┌────────────────────────────────────────────────────────┐
│               退出体系: 电子宠物数值养成               │
│  · energy / hunger / affection / attention / health    │
│  · 离线/在线数值衰减时钟 (decayTimer)                  │
│  · 投喂蛋糕卷 / 吃药治疗 / 离线恶化数值逻辑            │
│  · 基于好感度数值等级解锁功能                          │
└──────────────────────────┬─────────────────────────────┘
                           │ 退出 (V2.4.1 彻底清理)
                           ▼
┌────────────────────────────────────────────────────────┐
│             保留并演进: V2.4 角色认知语义状态           │
│  1. 认知心境与情绪 (Emotional State):                  │
│     happy | calm | shy | thinking | concerned | serious│
│  2. 运行模式 (Persona Mode):                           │
│     daily (流萤日常温和态) vs work (萨姆专注执行态)   │
│  3. 当前行为与场景姿态 (Behavioral & Activity Intent):  │
│     idle | listening | chatting | playing_music        │
│  4. 关系认知 (Relationship Context):                   │
│     基于事实的开拓者羁绊与交互记忆 (非0-100数值)       │
│  5. 短期交互上下文 (Conversation Context):             │
│     最近交互时间戳、当前关注话题、任务状态             │
└────────────────────────────────────────────────────────┘
```

### 2.1 必须彻底退出的内容
1. **好感度 (`affection`) 体系**：流萤与开拓者的羁绊源于匹诺康尼的共同经历与深层信任，不应简化为 0-100 的数值好感度，更不应要求用户通过“点击摸头”来刷数值解锁对话；
2. **饱食度 (`hunger`) 与精力 (`energy`) 衰减机制**：流萤不是需要定时喂食和打针的电子宠物。失熵症是不可逆的基因身世背景（由 Persona/Lore 表达），绝不应作为“饥饿/疲劳数值惩罚”来惩罚用户；
3. **照料交互 (`CareActionType`)**：喂食 (`feed`)、治疗 (`treatment`) 等数值维护操作退出主角色模型；
4. **离线惩罚时钟 (`decayTimer` / `applyOfflineTime`)**：用户打开应用不应面对“流萤因离线太久饥饿生病”的负反馈。

### 2.2 必须保留与语义化重构的内容
1. **当前心境与情绪状态 (`EmotionalState`)**：
   - 保留情绪维度的动态表现（如 `happy`, `calm`, `shy`, `thinking`, `surprised`, `serious`, `concerned`）；
   - 情绪由 **LLM 意图识别、上下文共鸣与交互情境** 驱动，而非由饱食度/精力数值推导；
2. **模式与声线状态 (`PersonaMode`)**：
   - 保留 `daily`（流萤日常少女态）与 `work`（萨姆专注执行态）的双层声线与交互风格切换；
3. **行为意图与 Live2D 映射 (`BehavioralIntent`)**：
   - 保留 19 个 Live2D 动作的语义映射（如思考、开心、挥手、害羞、战斗执行等）；
4. **关系与记忆上下文 (`RelationshipContext`)**：
   - 关系状态由 **Memory v2 记忆图谱与约定记录** 承载，而非单调数字；
5. **交互时间线 (`InteractionTimeline`)**：
   - 保留上次交互时间戳，用于合理判断空闲状态以触发温和的关心问候，而非数值衰减。

## 3. V2.4 新型角色语义状态模型建议 (Character Semantic State)

建议在后续重构中引入类型：

```typescript
export interface CharacterSemanticState {
  // 1. 运行模式 (日常 / 工作)
  mode: "daily" | "work";

  // 2. 当前心境与情绪 (由对话意图与上下文语义驱动)
  emotion: "happy" | "calm" | "shy" | "thinking" | "surprised" | "serious" | "concerned";

  // 3. 当前行为与活动场景
  activity: "idle" | "listening" | "chatting" | "playing_music" | "task_executing";

  // 4. 当前 Live2D 动作与表情
  currentAction: string;

  // 5. 时间戳记录 (仅用于空闲温和问候，不进行数值衰减)
  lastInteractionAt: number | null;
}
```
