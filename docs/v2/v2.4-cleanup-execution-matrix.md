## 2. 旧 Numeric Pet State 控制线改造矩阵

| 控制线 / 路径 | 分类 | 当前状态 | 问题描述 | 目标 V2.4 行为 | 改造方案 | 处置动作 |
| :--- | :---: | :---: | :--- | :--- | :--- | :---: |
| `StateManager.actionTimer` (18s) | D | ACTIVE RESIDUE | 每 18 秒由旧定时器计算 `chooseIdleAction()` 并调用 `dispatchAction()` 发送 `IPC.LIVE2D_PLAY_ACTION`，绕过 Behavior 决策。 | 视觉动作完全由 Behavior Runtime 统一规划；定时器不得直接向 Live2D 派发动作。 | 移除 `actionTimer` 中的 `dispatchAction` 调用，仅记录调试日志。 | **REFACTOR** |
| `StateManager.proactiveTimer` (45s) | D | ACTIVE RESIDUE | 每 45 秒由旧定时器触发 `proactiveAction()` 并调用 `dispatchAction()`，与 V2.4 `FireflyProactiveScheduler` 冲突。 | 主动陪伴行为由 `FireflyProactiveScheduler` 调度并通过 Agent Core 执行；旧状态定时器不得独立驱动 Live2D。 | 移除 `proactiveTimer` 中的 `dispatchAction` 调用，仅记录调试日志。 | **REFACTOR** |
| `SpeakingMotionController.setSpeaking(false)` | D | ACTIVE RESIDUE | 语音播放结束时，强制调用 `manager.playActionId("idle")`，直接清除并覆盖了 Behavior 赋予的 Live2D Expression/Motion。 | 语音播放结束时只停止口型同步（`mouthSync.stop()`），不强行切回 `idle`，视觉表情遵循 Embodiment 生命周期。 | 移除 `manager.playActionId("idle")` 强切调用。 | **REFACTOR** |
| `CharacterStateManager` 基础功能 (decay/save/getState/careAction) | B | COMPATIBILITY | 供 `ProactiveScheduler` 判断条件、供 `Settings` 保存与供用户交互 (`click`/`touch`/`drag`) 反馈。 | 维持基础数值衰减与持久化支持，不参与智能体认知决策。 | 完整保留类与交互方法。 | **KEEP** |
