### 3.2 召回分支对比
- **Lexical-only (词法分支)**：在精准实体、短语、卡片标题及人设问答中表现极佳（Recall@1 = 90%）；
- **Vector-only (当前特征向量分支)**：辅助捕获字符重叠特征，但缺乏深度语义泛化；
- **Hybrid + KnowledgeReranker (融合重排)**：在实体加权（0.35）、权威优先级（0.10）与对抗性门控协同下，达到 95% Recall@1 与 0.9500 MRR。

## 4. 权威重排与对抗性安全验证 (Adversarial Gating)

- **场景**: 针对无关查询（如“空间站防卫科负责人阿兰”），测试语料库中最高优先级（`canonicalPriority = 1.0`）的 `firefly.yaml` 是否会发生误召回；
- **表现**: `KnowledgeReranker` 成功触发内容相关性门控（`contentRelevance < 0.05`），将无关高优先级语料分数置 0，准确召回低优先级但高度相关的 Wiki 切片。

---

## 5. 已知限制与生产环境接入路径 (Known Limitations & Upgrade Path)

1. **当前局限**:
   - `DeterministicEmbeddingProvider` 仅依赖字符特征投射，无法理解无重叠同义词（例如将“点心”关联到“蛋糕卷”需依赖实体与词法字典扩展）；
2. **生产升级路径**:
   - 当用户在 `config/settings.json` 中配置本地 ONNX 模型路径或 OpenAI-compatible API Key 时，`ProductionEmbeddingProvider` 可自动切换为生产语义模式；
   - **上层 `HybridRetriever`、`RagSlot` 与 `FireflyAgentCore` 零修改**。
