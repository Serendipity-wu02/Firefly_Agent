# V2.3 Phase 4: RagSlot → ContextManager Runtime Integration

## 1. 阶段概述

在 V2.3 Phase 1（语料标准化）、Phase 2（向量存储与索引）、Phase 3（混合检索与重排序）及 Production Embedding Qualification（生产资格审计）的基础上，Phase 4 实现了 **RAG 检索层与上下文管理层（ContextManager）的解耦集成**。

```
User Query (userPrompt)
      ↓
KnowledgeCoordinator / RagSlot (Adapter)
      ↓
HybridRetriever (Lexical 50 + Dense Vector 50)
      ↓
KnowledgeReranker (5-Dimensional Score + Relevance Gate)
      ↓
KnowledgeProjector (800 Token Budget, Provenance, Canonical Tags)
      ↓
ContextManager (Slot Priority: 70)
      ↓
FireflyAgentCore (0 Direct RAG Imports)
```

---

## 2. 核心架构与解耦设计

### 2.1 依赖倒置与插槽适配 (RagSlot & Adapter)
- **零具体依赖**：`src/main/agent/context/context-slots.ts` 中的 `RagSlot` 不直接引用任何 RAG 内部具体类（如 `VectorStore`, `HybridRetriever`, `EmbeddingProvider`），仅定义轻量 Adapter 接口：
  - `IKnowledgeRetrieverAdapter`
  - `IKnowledgeProjectorAdapter`
- **优先级定位**：`RagSlot` 严格遵守上下文层级设计，设定优先级为 `70`：
  - System Prompt (100) > Character State (90) > Memory (80) > **RAG (70)** > Tool Schema (60) > Plan / History (50).

### 2.2 知识库协调器 (KnowledgeCoordinator)
- 位于 `src/main/rag/knowledge-coordinator.ts`；
- 作为装配与生命周期统一入口，管理 `FileVectorStore`、`DeterministicEmbeddingProvider`、`HybridRetriever` 与 `KnowledgeProjector`；
- 提供工厂方法 `createRagSlot(options)`，在 Composition Root (`src/main/index.ts`) 统一挂载至 `ContextManager`。

### 2.3 知识投影与 Token 预算控制 (KnowledgeProjector)
- 结构化 Markdown 注入格式：
  ```markdown
  【相关背景知识】 (Canonical Knowledge)
  - [facts.yaml] 【流萤 - 设定事实】前格拉默铁骑「萨姆」驾驶员，编号 AR-26710... (来源: 亲历) (权威度: 0.95)
  - [秘密基地.md] 【秘密基地】在流梦礁的边缘，流萤向开拓者坦白了自己身患失熵症的真相... (权威度: 0.85)
  ```
- **预算控制**：默认上限 `800 tokens`（可通过 `RagSlotOptions` 配置）。超出时优先保留重排序后高排名切片，并在单条切片过长时智能截断。
- **空结果与故障隔离**：当未检索到相关切片或检索过程发生异常时，安全返回空字符串 `""`，零 token 注入，不影响 Agent Core 正常运行。

### 2.4 双轨隔离与只读边界 (Memory vs RAG)
- **只读知识库**：RAG 仅从 `data/knowledge/` 读取规范知识语料，绝对不向 `MemoryStore` 或 `memory_v2.json` 写入任何记录。
- **独立上下文**：`MemorySlot` 与 `RagSlot` 平级并存，在 `ContextProjector` 中分别渲染为 `【长期记忆】` 与 `【相关背景知识】`，互不污染。

## 3. 生产 Embedding 资格说明

- **当前状态**：`TEST EMBEDDING MODE` / `PRODUCTION EMBEDDING: NOT QUALIFIED`
- **说明**：当前检索流水线由 `DeterministicEmbeddingProvider` 驱动，提供可靠测试与基础向量检索验证；生产级本地/远程权重接入预留于 V2.3 资格配置之后，不影响插槽与上下文的完整链路运转。
