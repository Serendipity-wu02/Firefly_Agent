## 2. Context 数据流架构 (Context Data Flow)

```mermaid
flowchart TD
    UserInput["HarnessInput (userPrompt, history, characterState, memoryContext)"] --> CM["ContextManager (Facade)"]
    
    subgraph ContextSlots ["🧩 Context Slot Layer"]
        CM --> SlotSys["SystemPromptSlot (Priority: 100)"]
        CM --> SlotState["CharacterStateSlot (Priority: 90)"]
        CM --> SlotMem["MemorySlot (Priority: 80 - Memory v2 Ready)"]
        CM --> SlotRag["RagSlot (Priority: 70 - RAG Ready)"]
    end
    
    subgraph PromptRendering ["📝 System Prompt Builder"]
        SlotSys --> SPB["SystemPromptBuilder.build()"]
        SPB --> Persona["流萤 3 层人设 (resources/firefly.yaml)"]
        SPB --> Actions["19 个日常动作清单 (FIREFLY_ACTIONS)"]
        SPB --> State["实时角色状态 (CharacterStateData)"]
        SPB --> Memory["长期记忆上下文 (MemoryItem[])"]
    end

    subgraph Projector ["⚡ ContextProjector & Token Accounting"]
        CM --> Projector["ContextProjector.project()"]
        Projector --> Meter["TokenMeter (estimateTokens / actualTokens)"]
        Projector --> Budget["computeContextBudget (PressureRatio, NeedsCompaction)"]
    end

    Projector --> Output["ProjectedContext:\n- messages: ChatMessage[] (System + History + User)\n- usage: ContextUsageSnapshot\n- systemPrompt: string"]
    Output --> AgentLoop["FireflyAgentCore Agent Loop / Session"]
```

## 3. V1 → V2 Context 映射关系 (Mapping Table)

| V1 Context 机制 | V2.1 Context Layer 映射 | 改进与演进优势 |
| :--- | :--- | :--- |
| `harness-context.ts` | `src/main/agent/context/*` 独立目录 | 彻底解耦，消除对 legacy harness 的代码依赖 |
| `buildFireflySystemPrompt()` | `SystemPromptBuilder.build()` | 职责单一化，流萤人设、状态字符串与动作列表独立格式化 |
| `buildRoundMessages()` | `ContextManager.buildInitialMessages()` | 支持插槽扩展，自动完成 User 消息末尾安全补全 |
| 无 Token 计量 | `TokenMeter` (可注入 `ITokenizer`) | 支持模型定制 Tokenizer，精确跟踪输入/输出 Token 消耗 |
| 无动态预算配额 | `ContextBudget` & `ContextUsageSnapshot` | 自动计算可用输入预算 (`UsableInput`) 与上下文压力比率 (`PressureRatio`) |
| 记忆/设定硬编码拼接 | `IContextSlot` 插槽系统 | 预留 `MemorySlot` 与 `RagSlot`，未来无缝接入 Memory v2 与 RAG |
