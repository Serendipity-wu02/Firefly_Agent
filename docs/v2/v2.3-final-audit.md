# Firefly-Agent V2.3 Final Audit & Release Certification

## 1. 架构总览 (V2.3 Architecture)

Firefly-Agent V2.3 在 V2.1 Agent Core 与 V2.2 记忆系统（Memory v2）的基础上，完整构建了 **规范知识库检索增强生成系统（RAG Pipeline）**，并实现了多模态子系统（Live2D-only 角色渲染、GPT-SoVITS 语音推理、桌面交互控制）的高内聚、低耦合集成。

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Firefly-Agent V2.3 Architecture                 │
├────────────────────────────────────────────────────────────────────────┤
│ 1. Canonical Knowledge Corpus (Read-Only)                             │
│    resources/ (806 files) ──> KnowledgeIngestionService ──> chunks.json│
│                               (5665 Chunks, SHA-256 Manifest)         │
├────────────────────────────────────────────────────────────────────────┤
│ 2. Dense Vector & Storage Layer                                        │
│    IEmbeddingProvider ──> VectorIndexService ──> FileVectorStore       │
│    (Deterministic / Test Mode)                   (vector_index.json)   │
├────────────────────────────────────────────────────────────────────────┤
│ 3. Multi-Stream Retrieval & Reranking                                  │
│    User Prompt ──> LexicalRetriever (50) + VectorRetriever (50)        │
│                ──> KnowledgeReranker (5-Feature Scoring + Gating)      │
├────────────────────────────────────────────────────────────────────────┤
│ 4. Context & Decoupling Layer                                          │
│    RagSlot (Priority: 70, 800 Tokens) + MemorySlot (Priority: 80)     │
│    ──> ContextManager ──> ContextProjector / Compactor                 │
├────────────────────────────────────────────────────────────────────────┤
│ 5. Agent Core & Runtime Layer                                          │
│    FireflyAgentCore (0 Direct RAG Imports, 0 Memory Direct Imports)    │
│    ──> ToolExecutionEngine ──> Live2D / Music / TTS Tools              │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. 规范知识语料库 (Canonical Corpus & Ingestion)

- **物理资源源**：`resources/` 目录保留 **806 个源文件**（12.68 MB），在全开发与测试周期中受只读保护，`git diff -- resources/` 严格为 **0**。
- **语料解析产物**：
  - `data/knowledge/documents.json`：806 个标准化知识文档对象。
  - `data/knowledge/chunks.json`：**5,665 个切片**，涵盖 5 大切片器（`AtomicFactChunker`, `YamlPersonaChunker`, `HeadingMarkdownChunker`, `LoreChunker`, `FixedSizeChunker`）。
  - `data/knowledge/manifest.json`：806 条文件的 SHA-256 哈希清单，确保切片与源文件 100% 可追溯。

---

## 3. 向量存储与增量同步 (Vector Store & Indexing)

- **存储规范**：`FileVectorStore` 实现 `IVectorStore` 标准接口，基于模式版本 v1 (`data/knowledge/vector_index.json`)，支持原子落盘、损坏自动备份（`.bak`）与优雅恢复。
- **切片向量**：5,665 条切片完整建立 384 维向量索引。
- **增量同步**：`VectorIndexService` 支持基于切片内容哈希的比对更新，重复同步 100% 跳过，源文件删除自动清理孤立向量。

---

## 4. 混合检索与重排序 (Hybrid Retrieval & Reranking)

- **双流召回**：
  - `LexicalRetriever`（词法倒排与实体分词）：候选池容量 50。
  - `VectorRetriever`（稠密向量相似度）：候选池容量 50。
- **5 维融合打分**：
  - Lexical Score (0.35)
  - Vector Score (0.30)
  - Canonical Priority (0.15)
  - Entity Relevance (0.15)
  - Timeline Relevance (0.05)
- **相关性门控（Adversarial Gating）**：强制要求查询关键词或语义相似度达到基本阈值，杜绝“无关高权威切片自动挤占上下文”的问题。

---

## 5. RagSlot 与上下文解耦集成 (RagSlot & ContextManager)

- **接口适配**：`RagSlot` 仅依赖 `IKnowledgeRetrieverAdapter` 与 `IKnowledgeProjectorAdapter`，Context 层零导入 RAG 具体类。
- **插槽优先级**：严格维持 `70`（System 100 > Character State 90 > Memory 80 > **RAG 70** > Tool 60 > Plan 50）。
- **Token 预算**：`800 tokens` 严格上限约束，高分切片优先保留与单段截断。
- **故障隔离**：检索异常或无匹配结果时，优雅降级返回空字符串 `""`，零 token 污染。

---

## 6. 系统边界审计 (System Boundaries)

### 6.1 Agent Core 边界
- `src/main/agent/firefly-agent-core.ts` 静态搜索：**0 处 RAG 模块导入**、**0 处 Memory 模块导入**。
- Agent Core 仅面向 `ContextManager` 抽象插槽与 `FireflyToolRegistry`。

### 6.2 Memory / RAG 边界
- `resources/` 与 `data/knowledge/` 为只读 Canonical Knowledge；
- `MemoryStore` 与 `memory_v2.json` 为用户个性化记忆；
- RAG 检索绝不修改 Memory；Memory 检索绝不侵入 Vector Store。

### 6.3 统一 Token 计算与压缩
- 全插槽统一使用 `TokenMeter`；
- 上下文渲染经由 `ContextProjector` 与 `ContextCompactor`，无后门旁路。

### 6.4 Live2D 角色与资产边界
- `assets/firefly/models/` 唯一正式源，6 项 Motion 与 11 项 Expression 全路径 100% 解析通过。
- 10 个 AI Allowed Actions 全覆盖，19 个历史 PNG 动作及其资产完全清理。
- PNG 运行时残留 = 0，SAM 状态机残留 = 0。

### 6.5 TTS 语音链路
- GPT-SoVITS $\rightarrow$ `TtsSessionService` $\rightarrow$ `SpeakingMotionController` $\rightarrow$ `MouthSyncController`（`ParamMouthOpenY`）全链路 100% 通过。
