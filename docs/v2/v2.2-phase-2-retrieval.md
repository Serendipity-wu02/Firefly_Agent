## 1. 架构定位与工作流 (Architecture & Pipeline)

Phase 2 建立了独立的纯只读记忆检索层，连接底层数据存储与排序管道：

```text

│                       MemoryQuery                           │
│  (queryText, entities, layer, scope, category, topK, etc.)  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                      MemoryRetriever                        │
│ 1. 只读读取 IMemoryStore 候选记录                            │

                               │
                               ▼

│                        MemoryRanker                         │
│ 综合五维打分评估 (Entity, Text, Importance, Recency, Conf)   │

```

## 2. 打分公式与权重体系 (Ranking Formula)

综合相关度评分由 5 个可配置维度的加权求和构成：
$$Score = w_{entity} \cdot S_{entity} + w_{text} \cdot S_{text} + w_{imp} \cdot Importance + w_{rec} \cdot S_{recency} + w_{conf} \cdot Confidence$$

### 2.1 默认权重配置 (`DEFAULT_RETRIEVAL_POLICY`)
- **实体相关度 ($w_{entity}$)**: `0.35`（精确匹配 `key` / `entities` 得分 1.0；包含匹配得分 0.8；`value` 包含得分 0.5）；
- **文本相关度 ($w_{text}$)**: `0.25`（完全匹配得分 1.0；包含匹配得分 0.9/0.75；多词覆盖比例匹配得分最高 0.6）；
- **基础重要性 ($w_{imp}$)**: `0.20`（直接采用 `record.importance`，取值范围 $[0.0, 1.0]$）；
- **时间新鲜度 ($w_{rec}$)**: `0.10`（采用指数衰减模型 $e^{-\frac{\ln 2 \cdot \Delta t}{\tau}}$，其中半衰期 $\tau = 7\text{天}$；`pinned: true` 固化记忆得分为 1.0）；
- **记录置信度 ($w_{conf}$)**: `0.10`（直接采用 `record.confidence`，取值范围 $[0.0, 1.0]$）。

## 3. 核心机制保障 (Core Invariants)

1. **作用域强隔离 (Scope Isolation)**:
   - 支持 `user`、`character`、`session`、`global` 严格单选或数组白名单过滤，杜绝跨会话或跨作用域数据串扰。
2. **确定性稳定排序 (Deterministic Tie-Breaking)**:
   - 得分相同时，优先按 `createdAt` 降序排列；若时间仍然相同，按 `id` 字典升序排列，杜绝偶发排序颠倒。
3. **容量截断保证 (Top-K Boundedness)**:
   - 严格保证返回结果条目数 $\le \text{topK}$。
4. **只读不可变安全 (Store Mutation Safety)**:
   - 检索全过程为 100% 纯函数与只读查询，对 `IMemoryStore` 执行 0 增删改操作。
5. **空查询安全兜底 (Empty Query Fallback)**:
   - 当 `queryText` 与 `entities` 均为空时，依据重要性 (60%)、新鲜度 (20%) 与置信度 (20%) 自动召回最具价值的核心记忆，避免检索崩溃。
