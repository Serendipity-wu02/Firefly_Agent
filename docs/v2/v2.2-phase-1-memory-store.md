## 1. 架构定位与职责边界 (Scope & Boundary)

Phase 1 聚焦于建立纯粹且严格类型化的记忆底层数据模型与存储引擎：
- **解耦隔离**：存储引擎不依赖 Electron/UI、不依赖 Agent Core、不依赖 TTS/Live2D/QQ Music；
- **纯粹存储**：不包含 Retrieval、不包含 Importance 评分、不包含 Decay、不包含 Write Policy、不包含 Conflict Resolution；
- **V1 兼容**：不破坏旧版 `FireflyMemoryService`，为现有 `memory.json` 提供只读兼容加载能力。

## 2. 交付代码清单 (Delivered Artifacts)

1. **`src/main/memory/memory-types.ts`**:
   - `MemoryLayer` (`"L0_WORKING" | "L1_EPISODIC" | "L2_SEMANTIC"`)
   - `MemoryScope` (`"global" | "user" | "character" | "session"`)
   - `MemoryCategory` (`"profile" | "preference" | "entity" | "relation" | "event" | "working_state"`)
   - `MemoryRecord`: 包含 `id`, `layer`, `category`, `scope`, `key`, `value`, `summary`, `importance`, `confidence`, `accessCount`, `createdAt`, `updatedAt`, `lastAccessedAt`, `expiresAt`, `source`, `pinned`, `metadata`
   - `EntityNode`: 包含 `id`, `name`, `type`, `aliases`, `description`, `importance`, `scope`, `updatedAt`
   - `RelationEdge`: 包含 `id`, `subject`, `predicate`, `object`, `sentiment`, `confidence`, `sourceMemoryId`, `scope`, `updatedAt`
   - `PreferenceItem`: 包含 `id`, `category`, `subject`, `polarity`, `intensity (1-5)`, `reason`, `scope`, `updatedAt`
   - `MemoryStoreSnapshot`: 包含 `version: 1`, `updatedAt`, `records`, `entities`, `relations`, `preferences`

2. **`src/main/memory/memory-store.ts`**:
   - `IMemoryStore`: 标准 CRUD、多维过滤、重载与刷盘契约；
   - `InMemoryMemoryStore`: 内存级存储实现；
   - `FileMemoryStore`: 具备 `${filePath}.tmp` $\rightarrow$ `rename` 原子写入、模式版本校验、损坏文件 `.corrupt.${timestamp}.bak` 隔离与旧版 V1 `memory.json` 兼容只读解析。

3. **`tools/test_v2_memory_phase1_store.mjs`**:
   - 8 项核心专项测试，覆盖 Record / Entity / Relation / Preference CRUD、多维过滤隔离、原子持久化、损坏恢复与 V1 兼容加载。
