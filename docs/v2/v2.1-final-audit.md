## 2. 核心模块与审计结论 (Comprehensive Audit)

### 2.1 Context Layer
- **TokenMeter**：统一估算与精确计算 Token，支持多模型 tokenizer 注入。
- **ContextSlots**：标准化插槽架构（SystemPrompt, CharacterState, Memory, RAG, Plan）。
- **ContextBudget**：动态上下文压力度量与无损预算规划。

### 2.2 Compaction Layer
- **投影纯度**：只压缩大模型临时可见投影，`AgentSession` 原始消息历史严格保持 100% 完整不变。
- **Paired Safe Cut**：大模型 Tool Calls 与对应的 Tool Results 严格原子成对截断，防止协议撕裂。
- **分级压缩策略**：支持 Soft（只修剪工具结果）、Hard（修剪 + 安全截断 + 总结节点）、Emergency（紧急超限极简压缩）。

### 2.3 Tool Execution & Policy
- **安全分级与授权**：`safe` 自动执行，`confirm_required` 与 `high_risk` 安全阻断。
- **并发与串行规划**：`read_only` 工具安全并发（`Promise.all`），`state_mutation` 状态修改工具严格顺序串行。
- **超时与暂态重试**：单工具超时通过 `AbortSignal` 熔断，暂态异常指数退避重试，永久性错误立即返回。
- **尺寸约束**：超限工具输出自动交由 Phase B `ToolResultPruner` 头尾采样修剪。

### 2.4 Recovery & Durability
- **错误分级体系**：400/413 超限触发 Emergency Compaction，429 限流触发指数退避，5xx 触发限定次数瞬态重试。
- **恢复预算**：`maxRecoveryAttempts = 3`，`maxOverflowRetries = 1`，结构性杜绝无限死循环。

### 2.5 Checkpoint & Resume
- **数据脱敏**：绝不序列化 `AbortController`、`Promise`、音频流、Electron 窗口句柄或 Tool 实例。
- **原子持久化**：`FileCheckpointStore` 采用 `${id}.tmp` $\rightarrow$ `${id}.json` 原子重命名写入与损坏文件安全隔离。
- **副作用安全防重复**：崩溃中断的 `started` / `unknown` 工具调用在恢复时主动注入 `interrupted_prior_to_completion` 标记，拒绝盲目重复执行。

### 2.6 Bounded Planning (Phase E)
- **双模自适应**：普通对话自动走 Direct Mode（0 规划开销），复合任务自动切入 Bounded Planning Mode。
- **有界步数控制**：严格受 `maxSteps`（默认 5 步）约束，杜绝死循环规划。
- **Step 生命周期与验证**：定义 `pending` $\rightarrow$ `running` $\rightarrow$ `verifying` $\rightarrow$ `completed` / `failed` 状态机，每步产出经 `StepVerifier` 确定性校验。
- **取消与超时联动**：用户取消或全局超时同步中断 Plan、Step、LLM 与 Tool 调用。

## 3. 三层状态边界与事件模型 (State & Event Isolation)

### 3.1 三层状态解耦
1. **AgentSession**：内存中只追加保存纯净的对话历史（`ChatMessage[]`）；
2. **RunExecutionState**：运行时的瞬态调度状态（状态机、当前 Step、活跃工具、Plan 现场、恢复计数）；
3. **Checkpoint**：带版本号与脱敏的现场持久化快照。

### 3.2 完整统一事件模型
- **V1 核心事件**: `agent:started`, `agent:step-start`, `agent:llm-request`, `agent:assistant-message`, `agent:tool-call`, `agent:tool-result`, `agent:final-answer`, `agent:cancelled`, `agent:error`, `agent:finished`
- **Phase C 工具事件**: `tool:authorized`, `tool:denied`, `tool:retry`, `tool:timeout`
- **Phase D 恢复快照事件**: `checkpoint:created`, `checkpoint:restored`, `recovery:started`, `recovery:completed`, `recovery:failed`, `run:resumed`
- **Phase E 规划事件**: `plan:created`, `plan:started`, `plan:step-start`, `plan:step-completed`, `plan:step-failed`, `plan:verification`, `plan:completed`, `plan:failed`, `plan:cancelled`
