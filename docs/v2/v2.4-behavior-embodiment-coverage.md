# Firefly-Agent V2.4: 行为表现层资源覆盖度审计 (Behavior Embodiment Coverage Audit)

- **版本基线**: Firefly-Agent V2.4 (`firefly-v2.4-alpha1`)
- **审计时间**: 2026-09-01
- **审计目标**: 只读审计当前 `assets/firefly/models/` 与 TTS 表现层真实资源，评估 8 大高维行为语义（`BehaviorType`）在视觉（Live2D Motion/Expression）与声音（Voice Delivery）维度的覆盖完整度，记录未来 Embodiment 阶段的演进缺口。
- **治理原则**: **本阶段仅做覆盖度审计，严禁修改 `assets/` 文件，严禁临时生成伪动作。**

## 1. 现有表现层资产盘点 (Live2D & TTS Inventory)

### 1.1 Live2D 现有 11 项表情 (Expressions)
- `expression00`: 平静自然 (Neutral / Calm)
- `expression1`: 温和微风笑意 (Soft Gentle Smile)
- `expression2`: 轻声关切/轻微疑问 (Slight Concern / Gentle Question)
- `expression3`: 睁大双眼意外 (Wide-Eyed Surprised)
- `expression4`: 欣慰暖意/感动欢喜 (Happy / Touched Warm Smile)
- `expression5`: 托腮沉思 (Thinking / Contemplative Gaze)
- `expression6`: 闭目养神 (Sleepy / Resting Eyes Closed)
- `expression7`: 弱气伤感/失熵不适 (Sad / Weak / Downcast Gaze)
- `expression8`: 认真坚定/战斗护盾态 (Determined / Serious / Focused)
- `expression9`: 说话开口状态 (Talking / Viseme Base)
- `expression10`: 侧头脸红害羞 (Shy / Blushing Head Tilted)

### 1.2 Live2D 现有 6 项动作曲线 (Motions)
- **Idle 组 (常态待机)**:
  - `Motions_Tick2_0_File_0.json` (`Idle/0`): 标准呼吸站立待机
  - `Motions_Tick2_1_File_0.json` (`Idle/1`): 低头专注阅读/思索待机
  - `Motions_Tick2_2_File_0.json` (`Idle/2`): 微幅晃动自然呼吸待机
- **Tap 组 (互动触发)**:
  - `Motions_表情组_0_File_0.json` (`Tap/0`): 顿挫反应/受控移动反馈
  - `Motions_表情组_1_File_0.json` (`Tap/1`): 举手轻快挥手打招呼
  - `Motions_表情组_2_File_0.json` (`Tap/2`): 享用甜点美食进食动作

### 1.3 TTS 声音表现力能力
- **引擎支持**: GPT-SoVITS, Custom Cloud, MiniMax, Mimo, Mossland；
- **声学特征控制**: 语速放慢/加快、音调轻柔/低沉、气声比例、标点停顿长短；
- **唇形同步**: `ParamMouthOpenY` 基于音频振幅实时调制。

## 3. 后续 Embodiment 阶段演进候选清单 (Future Embodiment Backlog)

本次审计确认现有 11 个表情与 6 个动作已经能 **100% 满足 8 大行为语义的基本外显映射**，但在表现细腻度上记录以下进阶候选：

1. **`Motion: gentle_lean_comfort`** (关怀倾听前倾动作)：用于 `comfort_user` 行为，当用户表达严重难过或疲惫时身体微微前倾；
2. **`Motion: sam_tactical_stand`** (机甲战备姿态)：用于 `work_mode` 下的高能执行态，展现萨姆护盾战术站姿；
3. **`TTS Prosody Stream Tags`** (流式韵律控制标签)：在 TTS session 传输时携带 `voiceExpressionIntent` 语义元数据，直接指导声学模型在关键句式处插入叹词气声。
