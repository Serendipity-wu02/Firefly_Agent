## 1. 架构模块逐项验收状态

### 1.1 Persona Acceptance — 【PASS】
- **单一真理源**: 唯一 Canonical Persona 文件冻结于 `resources/persona/firefly.yaml`，严格由 `PersonaLoader` 单向解析；
- **零设定硬编码**: 代码中彻底清除了任何硬编码的人设文本与 Prose Fallback；
- **防篡改与不可变性**: 对抗性 Prompt 无法修改底层 Persona 结构。

### 1.2 Knowledge Acceptance — 【PASS】
- **物理资源解耦**: 806 个世界观与设定资源物理迁移完成，分为 `world/`, `story/`, `knowledge/`, `linguistics/`, `character/`；
- **主观角色视角**: `CharacterKnowledgePerspective` 将客观知识（格拉默灭亡、铁骑背景）统一转化为流萤第一人称悲伤、坚韧与珍惜当下的人生体验；
- **零事实捏造**: 严禁在无官方依据的前提下编造角色经历。

### 1.3 Relationship Acceptance — 【PASS】
- **SSoT 架构**: `resources/character/relationships.yaml` 为唯一人物关系权威源，由 `RelationshipRegistry` 只读加载；
- **角色关系保真**: 开拓者（深度羁绊、信任、害羞）、星核猎手（家人、守护）、黑天鹅/黄泉（克制客气审视）；
- **外部角色非多情化**: 未知路人与外部势力人物严格标记为外部/世界观视角，不制造伪共同回忆。

### 1.4 Emotion Acceptance — 【PASS】
- **语义状态模型**: `SemanticInnerState` 包含 7 种权威语义情绪（`neutral`, `happy`, `shy`, `thinking`, `surprised`, `concerned`, `determined`）；
- **确定性判定**: 100% 确定性分类器，严格区分【外部用户身体不适/负向情绪 (`concerned`/`caring`)】与【流萤自身失熵症身体解离 (`thinking`/`reflecting`)】；
- **数值解耦**: 彻底脱离旧数值 `mood` / `affection` 状态。

### 1.5 Behavior Acceptance — 【PASS】
- **高维行为决策源**: `BehaviorRuntime` 基于优先级确定性仲裁 8 类角色行为（`comfort_user`, `restrained_response`, `share_memory`, `reflect_origin`, `focused_execution`, `explore_knowledge`, `warm_conversation`, `idle_presence`）；
- **行为唯一决策**: 行为决定“流萤如何行动”，作为下游 Text、Voice、Live2D 三路具身化的唯一仲裁点。

### 1.6 Embodiment Acceptance — 【PASS】
- **统一具身化计划**: `EmbodimentPlan` 由 `CharacterPolicyEngine.createEmbodimentPlan` 一次性编译；
- **三路表现一致性**: Text（纯口语回复）、Voice（声学微调与语音意图）、Visual（Live2D 真实动作）均来自同一行为；
- **全局唯一关联追踪**: `correlationId` (`emb-timestamp-type-counter`) 100% 贯穿计划、消息、TTS 与 Live2D 分发。

### 1.7 Harness Presentation Acceptance — 【PASS】
- **Cyrene 风格消息呈现**: Assistant 消息采用 `ChatMessageItem` 呈现（真实流萤头像 + 角色名 "流萤" + 纯净台词气泡 + TTS 播放控件）；
- **真实头像物理资产**: 严格使用 `src/renderer/head_portrait/firefly.png`，由 Vite 静态构建进入 `dist/renderer/assets/firefly-mE4lp41h.png`；
- **零占位符/假头像**: 彻底清除 assistant 的“萤”字占位徽章与假渐变 fallback；
- **自动与手动播放等价**: 手动点击 TTS 播放按钮与回复自动播放均读取 `ChatMessage` 上的 Embodiment 元数据，参数与语速严格等价。

### 1.8 Voice Acceptance — 【PASS】
- **真实能力边界**: `FireflyTtsDispatcher` 提取 `prosodyHint.pace` 调制实际语速（`slow`: 0.9x / `brisk`: 1.1x），下发至 GPT-SoVITS `speed_factor`、Custom Cloud 与 MiniMax；
- **未伪造参数**: 未将引擎不支持的 pitch / pause / volume 伪造为生效；
- **Cache 隔离**: Cache Key 仅纳入实际改变音频结果的参数（`text`, `speed`, `pace`, `behaviorType`, `engineConfigs`）；
- **纯净口语**: `speechText` 保持 100% 纯口语台词，无 `<slow>` / `<soft>` 等协议控制符污染。

### 1.9 Live2D Acceptance — 【PASS】
- **资产 0 修改**: 严格复用现有 11 个 Expression 与 6 个 Motion，`assets/` 0 diff；
- **真实动作调度**:
  - 用户不适 (`comfort_user`) $\rightarrow$ `actionId: "touched"` (`expression4` 欣慰触动)；
  - 用户夸奖 (`restrained_response`) $\rightarrow$ `actionId: "shy"` (`expression10` 脸红害羞)；
  - 美好回忆 (`share_memory`) $\rightarrow$ `actionId: "happy"` (`expression4` 喜悦欢喜)；
  - 自身失熵症 (`reflect_origin`) $\rightarrow$ `actionId: "sick"` (`expression7` 弱气沉思)；
  - 纯身世思考 (`reflect_origin`) $\rightarrow$ `actionId: "thinking"` (`expression5` 托腮思索)；
  - 工作任务 (`focused_execution`) $\rightarrow$ `actionId: "reading"` (`Idle/1` 专注阅读待机)；
- **IPC 贯穿**: `IPC.LIVE2D_PLAY_ACTION` 载荷携带 `correlationId` 与 `behaviorType`。

### 1.10 Memory Boundary Acceptance — 【PASS】
- **记忆只读影响**: 用户长期记忆（偏好、约定）可作为上下文影响个性化行为决策（如选择回忆话题）；
- **边界保护**: Memory 绝不是 Persona 源、Relationship 源或 Canonical Knowledge 源；
- **防篡改保护**: 用户无法通过记忆或对话改写流萤身世、性格或官方关系设定。

### 1.11 Legacy Numeric State Isolation — 【PASS】
- **彻底隔离**: 旧数值宠物状态（`affection`, `hunger`, `energy`, `health`, `attention`, `decay`, `feeding`, `treatment`）已完全退出角色决策层；
- **不变性验证**: 输入极低数值与极高数值状态，角色的语义情绪、行为决策与具身化计划 100% 相同。
