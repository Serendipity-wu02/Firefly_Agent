## 3. 溯源与指纹管理机制 (Provenance & Fingerprint)

1. **来源可追溯性 (Full Provenance)**:
   - 每个 `KnowledgeChunk` 均严格绑定 `documentId`、`sourceUri`（相对 `resources/` 真实路径）、`chunkIndex`、`headingPath` 与 `metadata.sourceFile`，可精确追溯回原始文件；
2. **SHA-256 指纹跟踪 (Fingerprint)**:
   - 为全部 806 个文件生成唯一的 64 位 SHA-256 校验和；
   - 摄取引擎支持在文件哈希未变时直接跳过重复解析，保障秒级增量更新；
3. **确定性 ID 生成 (Deterministic IDs)**:
   - `sourceId`、`documentId`、`chunkId` 采用相对路径与索引的确定性散列构建，多次执行保持 100% 幂等。
