# Firefly-Agent V2.4: 语料运行时多维元数据映射矩阵 (Runtime Metadata Matrix)

- **版本基线**: Firefly-Agent V2.4 (`firefly-v2.4-alpha1`)
- **核心架构准则**: 彻底贯彻 **Physical Storage ≠ SourceType ≠ KnowledgeLayer ≠ Priority ≠ Runtime Consumer** 的正交解耦原则。

---

## 1. 五维正交解耦模型 (Decoupled Dimensions)

```text
┌────────────────────────┐       ┌────────────────────────┐
│ 1. 物理存储 (Storage)   │  ───► │ 2. 分块协议 (SourceType)│
│  (磁盘目录与文件客观归属)│       │  (解析器与分块格式规则)│
└────────────────────────┘       └────────────────────────┘
                                              │
                                              ▼
┌────────────────────────┐       ┌────────────────────────┐
│ 4. 权威权重 (Priority)  │  ◄─── │ 3. 认知层 (Knowledge)   │
│  (召回决胜与重排序系数) │       │  (主观视角与认知边界)  │
└────────────────────────┘       └────────────────────────┘
              │
              ▼
┌────────────────────────┐
│ 5. 运行时 (Consumer)   │
│  (消费该知识的模块逻辑)│
└────────────────────────┘
```

### 核心设计事实：
**同一物理目录中的资料，可以且应当具有不同的 Runtime Metadata。**

例如：
- `resources/world/characters/卡芙卡.txt`:
  - 物理存储: `world/characters/` (客观世界自机角色百科)
  - 分块协议: `character_encyclopedia`
  - 认知层级: 由 `RelationshipRegistry.isKnownCompanion("卡芙卡")` 判定为已知同伴 $ightarrow$ 动态分配 `companion_relationship` 视角
  - 权威权重: 动态享受高优先权重
- `resources/world/characters/景元.txt`:
  - 物理存储: `world/characters/` (客观世界自机角色百科)
  - 分块协议: `character_encyclopedia`
  - 认知层级: 判定为未建立直接交集人物 $ightarrow$ 动态分配 `world_lore_external` 客观情报视角
  - 权威权重: 保持客观情报权重 (0.70)

## 3. `resources/firefly.yaml` 单一真源与兼容性原则

- **物理存储**: 目标规划为 `resources/persona/firefly.yaml`；
- **单一真源定位**: 始终作为流萤角色人格、身份底色、口癖、禁忌与 19 个 Live2D 动作规则的**唯一最高真源**；
- **兼容性保障**: 在物理迁移实施前，保持 `resources/firefly.yaml` 的只读物理路径有效，通过 Loader 兼容探测实现零中断过渡；
- **全链路调用者索引**:
  1. `src/main/character/persona-loader.ts`
  2. `src/main/character/character-policy.ts`
  3. `src/main/character/relationship-loader.ts`
  4. `src/main/character/knowledge-perspective.ts`
  5. `src/main/rag/chunkers/yaml-persona-chunker.ts`
  6. `src/main/agent/context/system-prompt-builder.ts`
  7. 全量自动化测试与分发套件。
