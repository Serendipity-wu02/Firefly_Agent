# Firefly-Agent V2.4: 语料运行时多维元数据映射矩阵 (Runtime Metadata Matrix)

- **版本基线**: Firefly-Agent V2.4 (`firefly-v2.4-alpha1`)
- **核心架构原则**: 彻底实现 **物理存储 (Storage) ≠ 分块类型 (SourceType) ≠ 认知层级 (KnowledgeLayer) ≠ 权威权重 (Priority)** 的四维解耦。

---

## 1. 四维解耦概念模型 (Decoupled Dimensions)

```text
┌────────────────────────┐       ┌────────────────────────┐
│ 1. 物理存储 (Storage)   │  ───► │ 2. 分块协议 (SourceType)│
│  (磁盘目录与文件组织)    │       │  (解析器与分块策略)    │
└────────────────────────┘       └────────────────────────┘
                                              │
                                              ▼
┌────────────────────────┐       ┌────────────────────────┐
│ 4. 权威权重 (Priority)  │  ◄─── │ 3. 认知层 (Knowledge)   │
│  (Rerank & Tie-Breaking)│       │  (主观视角与认知边界)  │
└────────────────────────┘       └────────────────────────┘
```

1. **物理存储 (Physical Storage)**: 仅反映文件的语料物理归属与资产类型，不带有任何运行时状态偏见；
2. **分块类型 (SourceType)**: 决定由哪一个 Chunker（如 `YamlPersonaChunker`, `MarkdownExperienceChunker`, `QuestChunker`）进行语义切分与元数据提取；
3. **认知层级 (KnowledgeLayer)**: 决定检索到该切片时，流萤以何种主观视角表达（如 `canonical_identity`、`first_person_experience`、`companion_relationship`、`world_lore_external`）；
4. **权威权重 (Canonical Priority)**: 在多路召回重排序时，当相关度相近时决胜的权威性系数（1.00 ~ 0.60）。

## 3. 特别审核：`resources/firefly.yaml` 单一真源定位

- **定位**: `resources/firefly.yaml` 始终是流萤角色人格、身份底色、口癖、禁忌与 19 个 Live2D 动作准则的**绝对最高单一真源**；
- **只读保证**: 在物理迁移规划中，仅规划将其规范放置于 `resources/persona/firefly.yaml` 或保持根目录 `resources/firefly.yaml`，当前阶段**严格保持 0 物理修改**；
- **全链路调用者索引**:
  1. `src/main/character/persona-loader.ts`
  2. `src/main/character/character-policy.ts`
  3. `src/main/character/relationship-loader.ts`
  4. `src/main/character/knowledge-perspective.ts`
  5. `src/main/rag/chunkers/yaml-persona-chunker.ts`
  6. `src/main/agent/context/system-prompt-builder.ts`
  7. 全部 Persona / SSoT / Distribution 自动化测试套件。
