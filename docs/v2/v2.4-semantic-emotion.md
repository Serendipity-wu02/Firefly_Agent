# Firefly-Agent V2.4: 角色语义情绪与内在状态架构规范 (Semantic Emotion & Inner State Architecture)

- **版本基线**: Firefly-Agent V2.4 (`firefly-v2.4-alpha1`)
- **执行时间**: 2026-09-01
- **核心定位**: **彻底终结旧“桌宠数值养成”（好感度、饱食度、精力值、离线衰减）路线，将角色状态升级为以 Persona 为根基的“语义内在状态”（Semantic Inner State）。**

---

## 1. 语义内在状态模型 (Semantic State Model)

```text
┌─────────────────────────────────────────────────────────────┐
│                 SemanticInnerState                          │
├─────────────────────────────────────────────────────────────┤
│ 1. emotion:            SemanticEmotion                      │
│    (neutral | happy | shy | thinking | surprised |          │
│     concerned | determined)                                 │
│ 2. cognitiveContext:   CognitiveContext                     │
│    (listening | conversing | task_executing | reflecting |  │
│     sharing_memory | caring)                                │
│ 3. mode:               CharacterMode                        │
│    (daily | work)                                           │
│ 4. explanation:        string (可解释的心境起因)            │
│ 5. expressionGuidance: string (来源于 firefly.yaml 的表达导引)│
│ 6. behavioralTendency: string (柔和/克制/坚定/高效等行为姿态)│
│ 7. timestamp:          number (评估生成时间戳)              │
└─────────────────────────────────────────────────────────────┘
```

### 1.1 七大语义情绪枚举 (SemanticEmotion)

与 [`resources/persona/firefly.yaml`](file:///e:/Google-Antigravity/working/Firefly-Pet/resources/persona/firefly.yaml) 中 `daily_mode.emotion_rules` 逐项精准对齐：

| 枚举值 | 情绪中文表达 | 规范行为与语气规则 | 触发语境示例 |
| :--- | :--- | :--- | :--- |
| **`neutral`** | 平静自然 | 平淡、轻声、不刻意讨好也不故作疏离，自然柔和 | 默认闲暇、通用问候 |
| **`happy`** | 温和欣慰 | 不是外放大笑型——开心时轻轻柔和下来，语气里多一分暖意，善用轻快短句与「嘿嘿」 | 分享美食、提及看星星/烟花/重逢 |
| **`shy`** | 羞涩拘谨 | 被夸奖或聊到害羞话题时，轻轻否认、目光移开、小声回一句，多带「…」停顿 | 夸奖外表、直接表白、亲密互动 |
| **`thinking`** | 专注沉思 | 会用「嗯…」「那个…」停顿，像一边思考一边小心说出来，理清线索 | 回忆格拉默身世、探究宇宙世界观 |
| **`surprised`** | 轻微意外 | 「哎？」「咦？」——轻声的意外，不会夸张，带好奇与错愕 | 出乎意料的提问或突发事件 |
| **`concerned`** | 关切担忧 | 伤感或关切时表现为停顿、轻声、话变少——不会失控，静静说出关怀与守护心意 | 感知到用户疲惫、难过、生病或挫折 |
| **`determined`** | 认真坚定 | 极少生气，仅在涉及保护重要之人或工作任务执行时展现坚定——声音变低变稳，果断 | 工作模式、执行指令、守护同伴 |

## 2. 确定性情绪解释器 (Deterministic Emotion Interpretation)

情绪计算完全基于多维上下文的确定性规则推导，**绝对禁止使用 `Math.random()` 产生随机情绪**：

```text
┌──────────────────────────────┐
│  User Prompt (用户输入)       │
│  Character Intent (意图分类)  │
│  Interlocutor (对话对象关系)  │ ───► SemanticStateInterpreter.interpret()
│  Knowledge (主观视角知识)    │
│  Memory Context (长期记忆)   │
│  Active Mode (daily / work)  │
└──────────────────────────────┘
               │
               ▼
┌──────────────────────────────┐
│     SemanticInnerState       │
│  - emotion                   │
│  - cognitiveContext          │
│  - explanation               │
│  - expressionGuidance        │
│  - behavioralTendency        │
└──────────────────────────────┘
```

## 3. 四大核心架构边界与不变性保障 (Invariance Guarantees)

1. **Persona 不变性 (Persona Invariance)**：
   - 情绪是瞬时心境，人格是长久底色；
   - 任何情绪变化**绝对禁止修改 `PersonaProfile`、`firefly.yaml` 或角色核心价值观**。
2. **Relationship 不变性 (Relationship Invariance)**：
   - 关系提供“我正在和谁交流”，情绪提供“我现在的心境”；
   - 情绪波动**绝对不会篡改已建立的官方同伴关系事实**。
3. **Memory Store 不变性 (Memory Invariance)**：
   - 本阶段仅只读检索 Memory 上下文辅助情绪判定；
   - 情绪解释器**绝对不会向 `MemoryStore` 自动写入任何记忆记录**。
4. **旧数值状态解耦 (Numeric State Independence)**：
   - 核心语义情绪判定完全脱离 `affection`、`hunger`、`energy`、`health`、`attention` 数值；
   - 保持现有 UI/IPC 兼容层的平滑运行，但不允许数值污染大语言模型认知。

## 4. System Prompt 结构化投影与 Token 控制

在 System Prompt 中，内在状态被投影为高语义、低 Token（~100 Tokens）的标准段落：

```markdown
【当前内在状态】
- 当前心境：温和欣慰（happy）
- 认知上下文：分享记忆
- 运行模式：日常陪伴模式
- 心境起因：提及喜爱的食物、美好回忆或重聚时光，心生暖意与欣喜。正在与最珍视的开拓者交流，语气自然亲近、多一份柔软。
- 表达倾向：不是外放大笑型——你开心时会轻轻地柔和下来，语气里多一分暖意
- 行为倾向：语气轻快柔和，流露真诚暖意，多用短句。
```
