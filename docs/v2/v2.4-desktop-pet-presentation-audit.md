```text
┌───────────────────────────────────────────────────────────┐
│ User Interaction (桌面物理点击 / 摸头 / 拖拽释放)           │
└─────────────────────────────┬─────────────────────────────┘
                              │
                              ▼
        Renderer: window.characterState.careAction()
                              │
                              ▼
             Main IPC: IPC.CARE_ACTION Handler
                              │
            ┌─────────────────┴─────────────────┐
            │ (兼容层数据更新)                   │ (唯一视觉决策)
            ▼                                   ▼
State: handleCareAction()          CharacterPolicyEngine
(更新数值/历史/返回统计)            .handleInteraction(action)
                                                │
                                                ▼
                                         EmbodimentPlan
                                  (携带 correlationId,
                                   behaviorType, visual target)
                                                │
                                                ▼
                                    WindowManager.sendToPet(
                                      IPC.LIVE2D_PLAY_ACTION,
                                      visual.target
                                    )
                                                │
                                                ▼

```

- **摸头 (touch)**: 映射为 `comfort_user` 行为语义，触发 `touched` 表情（`expression4` / 欣慰感动）。
- **点击身体 (click)**: 映射为 `warm_conversation` 行为语义，触发 `waving` 动作（`Tap/1` / 互动招手）。
- **拖拽释放 (drag)**: 映射为 `warm_conversation` 行为语义，触发 `dragged` 动作（`Tap/0` / 落地晃动）。

## 4. SpeakingMotionController 视觉覆盖问题修复

- **原问题**: `setSpeaking(true)` 强行执行 `manager.playActionId("talking")`，`setSpeaking(false)` 强行执行 `manager.playActionId("idle")`，导致 Behavior 赋予的生动表情（如羞涩 `shy`、欣慰 `happy`、感动 `touched`、沉思 `thinking`）在语音播放起止瞬间被覆盖清除。
- **修复方案**:
  - `SpeakingMotionController` 职责严格限制在口型同步控制；
  - `setSpeaking(true)` 仅调用 `this.mouthSync.start(durationMs)`；
  - `setSpeaking(false)` 仅调用 `this.mouthSync.stop()`；
  - **彻底移除一切表情与动作的自行切换逻辑**。

---

## 5. ExpressionResetController 视觉覆盖问题修复

- **原问题**: 任意表情被触发后，`ExpressionResetController` 固定在 5000ms 后调用 `manager.setExpression("")`，造成表情在 5 秒后被无条件重置为白板。
- **修复方案**:
  - `ExpressionResetController` 重置目标固定为官方默认表情 `expression00`；
  - 默认关闭无条件 5 秒定时器，仅在动作目标显式携带 `temporary: true` 时才启动定时重置；
  - 角色表情状态生命周期完全由 `BehaviorDecision` / `EmbodimentPlan` 决定。

## 9. Desktop Pet 唯一 Visual Decision Path

```text
BehaviorRuntime (决定高维行为倾向)
      ↓
EmbodimentAdapter (编译出唯一 EmbodimentPlan: Text, Voice, Visual)
      ↓
WindowManager.sendToPet(IPC.LIVE2D_PLAY_ACTION, visual.target)
      ↓
Live2DManager.playTarget(target)
      ↓
Canvas WebGL Render
```

- **Voice**: 仅负责音频回放与实时口型同步 (`ParamMouthOpenY`)；
- **Legacy State**: 仅保留状态持久化与兼容接口支持；
- **Live2D**: 唯一受控于 `EmbodimentPlan`。
