## 3. 架构裁决与单一真源落地说明 (Architecture Decision Record)

- **裁决结论**：采用 **Plan 3 — Canonical Persona Path Only**；
- **核心原则**：
  - **`resources/persona/firefly.yaml` 是流萤人设唯一绝对最高真源**；
  - 根目录不再保留 `resources/firefly.yaml` 兼容文件，杜绝任何双份文件、符号链接或硬链接所带来的环境不一致与真源分裂风险；
  - **V2.4 从此以新的 Canonical Path 为正式架构，不继续维护 V2.3 Root Compatibility Path**；
  - 全工程（`PersonaLoader`、`CharacterPolicyEngine`、`KnowledgeIngestionService`、`YamlPersonaChunker`、全量测试用例与 npm 分发配置）100% 统一收敛至 `resources/persona/firefly.yaml`。
