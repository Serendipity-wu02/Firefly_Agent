## 1. 架构总览与运行时数据流 (Runtime Flow)

Phase 5 完成了 Memory v2 与 Context Layer 的无缝缝合。`FireflyAgentCore` 仅面向 `ContextManager`，通过 `MemorySlot` 以只读方式获取格式化记忆投影，彻底实现存储引擎与推理内核的物理隔离。

```text
       User Query: "我之前喜欢什么歌？"
                      │
                      ▼
               ContextManager
                      │
                      ▼
                  MemorySlot (priority: 80)
                      │
                      ▼
               MemoryRetriever
                      │
                      ▼
                MemoryRanker
                      │
                      ▼
               MemoryProjector
         (格式化归纳 + Token Budget 截断)
                      │
                      ▼
           Formatted Memory Context
                      │
                      ▼
             System Prompt Builder
                      │
                      ▼
             FireflyAgentCore Loop
```

## 2. MemorySlot 上下文适配器设计 (MemorySlot Adapter)

`MemorySlot` 作为 `IContextSlot` 协议的实现，挂载于 `ContextManager` 中（默认优先级 80）：

1. **按需触发检索**: 当传入 `ctx.userPrompt` 且未显式指定 `ctx.memoryContext` 时，向 `MemoryRetriever` 发起 Top-K 语义与实体检索；
2. **优雅降级**: 若检索为空或未命中，返回空字符串，不产生冗余占位符；
3. **只读保证**: 槽位渲染期间 **零 Store 状态突变**，`accessCount` 与 `updatedAt` 保持原始状态。

## 3. 记忆投影与格式规范 (Memory Projection Format)

`MemoryProjector` 将底层的 `MemoryRecord` 数组物化为对 LLM 极度友好、结构清晰的文本段落：

```text
【流萤对开拓者的长期记忆】
• 基础画像: 代号: 开拓者
• 偏好喜好: 音乐: 使一颗心免于哀伤
• 关系纽带: 信任: 流萤
• 共同经历: 约定: 秘密基地看烟花
• 关联实体: 格拉默: 帝国故土
• 近期状态: 心情: 开心
```

### 3.1 Token 预算控制 (Token Budget Enforcement)
- 默认分配 500 Tokens 的记忆预算；
- 当多条记忆累计超出预算时，从尾部低优先级条目安全移除，确保 System Prompt 总体长度受控；
- 兼容 `ContextCompactor` 紧急压缩机制。

## 4. 边界隔离保障 (Boundary Isolation)

| 系统边界 | 隔离规则与实现保证 |
| :--- | :--- |
| **Agent Core 边界** | `FireflyAgentCore` **0 imports** from `src/main/memory/*`，不实例化任何 Memory 引擎，仅面向 `ContextManager`； |
| **Session 边界** | `AgentSession` 仅记录当前会话消息流水（Conversation History），绝不全量复制为长期记忆； |
| **Memory Write 边界** | 记忆写入必须经由 `MemoryWriteService` 的 `MemoryWritePolicy` 过滤，严禁所有对话自动入库； |
| **Maintenance 边界** | 衰减与过期清理仅由 `MemoryMaintenanceService` 显式/周期性触发，检索路径绝不执行全表重写； |
| **RAG 边界** | `resources/` 保持为只读的官方世界观真源（Canonical Lore），严禁注入 Memory v2，留待 V2.3 `RagSlot` 摄取。 |
