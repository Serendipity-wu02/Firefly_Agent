## 本轮纠正和边界

- 旧 docx 正文明确写有 MiniMax 作者与 minimax-docx 标题；名称 docx 并不能证明来源是 Anthropic。
- 旧 pdf/xlsx 已是 Windows-native 本地工作流。MiniMax 对应项目作为候选暂存，不能声称字节、来源历史或功能等同。
- office-design 的旧版本是跨格式主题与校验器，write-expense-report 依赖 query_expense / write_excel。未定位独立上游不等于证明不存在，也不等于可以任意删除现有实现。
- self-improvement 选择原作者多 Agent 仓库里附带 MIT 的 plugin 范围，是同作者变体，不冒充旧 OpenClaw 改造版本。
- ECC 的旧路径 affaan-m/everything-claude-code 返回迁移；本包锁定到当前 affaan-m/ECC 的具体提交。
- 不获取 Anthropic 的 docx/pdf/xlsx/pptx 作为这些办公技能的同名替代。Anthropic 的 skill-creator 使用其目录内独立 Apache-2.0 许可。
