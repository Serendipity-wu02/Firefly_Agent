# 飞书接入教程

本指南说明 Firefly 的飞书私聊接入。2026-09-26 已按本地适配器和设置代码核对；开放平台界面、账号资质及权限审批流程未作实机核验，下列平台步骤保留作对照，需以账号实际页面核实。

---

## 这个方案是怎么工作的

Firefly 的飞书适配器通过官方 SDK 使用 **WebSocket 长连接**；项目也提供 QQ 官方机器人适配器。使用官方接口不构成账号无风控或服务持续可用的保证。

```
你的飞书账号 ── 飞书服务器 ── WSS 长连接（官方 SDK） ── Firefly
```

此适配器由 **Firefly 主动连接**，不要求为它暴露入站回调端口；本机仍须能够访问飞书服务，代理、防火墙和账号权限会影响连接。

---

## 第 0 步：准备工作

- 一个能在目标租户创建、管理并发布自建应用的飞书账号。
- 账号资质、管理员权限及审核要求须在实际控制台核实；本指南不保证个人账号可自行审核或无需认证。

---

## 第 1 步：创建自建应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，登录飞书账号
2. 点「创建企业自建应用」，名字随意（比如 `Firefly`），描述随便写一句
3. 创建完成后进入应用详情页，左侧「凭证与基础信息」里能看到 **App ID** 和 **App Secret**——先复制保存，最后一步要用

> 注意：一定要选「企业自建应用」，不要选「商店应用」。自建应用只在自己团队内部用，免审核上架流程。

---

## 第 2 步：开启机器人能力

左侧「添加应用能力」→ 找到「机器人」→ 开启。

这是最关键的一步——不开机器人能力，后面所有权限和事件都无从谈起。

---

## 第 3 步：开通权限

左侧「权限管理」→ 搜索并开通以下权限：

| 权限 key | 权限名称 | 干什么用 | 必需性 |
| --- | --- | --- | --- |
| `im:message.p2p_msg:readonly` | 获取用户发给机器人的单聊消息 | **接收**你发给 Firefly 的私聊消息 | 必需 |
| `im:message:send_as_bot` | 以应用的身份发消息 | **发送** Firefly 的回复 | 必需 |
| `im:resource` | 获取与上传图片或文件资源 | **下载**你发来的图片/文件/语音 | 用多媒体则必需 |
| `im:image` | 上传图片 | Firefly **发送**图片（如生成图、截图回复） | 用则必需 |
| `im:file` | 上传文件 | Firefly **发送**语音/文件 | 用语音回复则必需 |

只想要文字聊天的话，前两个就够了。想收发图片/语音/文件，五个全开。

---

## 第 4 步：订阅消息事件

左侧「事件与回调」：

1. 订阅方式选择「**使用长连接接收事件**」（重要！选这个就不用填任何 URL）
2. 点「添加事件」→ 搜索 `接收消息` → 添加 **im.message.receive_v1**
3. 添加事件时平台会提示需要第 3 步里的权限，确认开通即可

---

## 第 5 步：设置可用范围

左侧「应用发布」→「版本管理与发布」之外，先看「应用功能」区域的「可用范围」：

- **建议设为"仅自己"**：Firefly 的飞书渠道当前没有用户白名单，可用范围内**任何成员**私聊机器人都会触发你的 Firefly。个人使用就把自己加进去即可

---

## 第 6 步：发布应用

1. 左侧「应用发布」→「版本管理与发布」→「创建版本」
2. 填个版本号（如 1.0.0）和更新说明（随便写）
3. 点「申请线上发布」
4. 因为你是自己团队的管理员，去飞书「管理后台」（或消息里收到的审核通知）**自己审核通过**即可。自建应用不会上架应用市场，只有团队内可见
5. 发布后机器人才真正生效——**不发布的话，事件收不到，机器人不回复**

---

## 第 7 步：在 Firefly 里配置

1. 系统托盘 → Firefly → 「设置」→「连接手机」→「飞书」卡片
2. 填入第 1 步复制的 **App ID** 和 **App Secret**
3. 打开渠道开关，点「保存并启动」
4. 状态变为「**长连接已建立**」表示连接成功，仍需下一步验证收发。App Secret 优先用 Electron `safeStorage` 保存，不可用或加密失败时会回退到 `obf2:` 混淆；混淆不等于系统加密，设置页不回填明文。

---

## 第 8 步：试一试

在飞书里搜索你的机器人名字（或在工作台找到这个应用），给它发一条私聊消息。

Firefly 回复了，接入完成。

---

## 消息规则说明

- **仅私聊**：适配器只处理 `p2p` 消息，其他类型被忽略；不承诺后续群聊功能。
- **多媒体收发**：图片/文件/语音/视频/表情包都能收（自动下载到本地缓存后交给 Firefly）；发送支持文本、图片、语音（自动转码为飞书 Opus 格式）、卡片
- **富文本/卡片**：Firefly 回复 Markdown 时会转成飞书卡片样式呈现
- **主动消息**：适配器支持发送消息，但实际主动投递还依赖应用开关、目标会话、平台权限及服务返回；真实投递未纳入该次适配器核对。

---

## 排障速查

| 症状 | 原因与解法 |
| --- | --- |
| 状态一直是「config_missing」 | App ID / App Secret 没填或填错，回第 1 步核对 |
| 连接建立但发消息没反应 | 应用**没发布**（第 6 步）；或事件没订阅 `im.message.receive_v1`；或订阅方式不是「长连接」 |
| 收得到消息但不回复 | `im:message:send_as_bot` 权限没开 |
| 图片/文件发过去 Firefly 说没有附件 | `im:resource` 权限没开 |
| 机器人发不出图片/语音 | 分别检查 `im:image` / `im:file` 权限 |
| 权限改了还是报权限错误 | 改权限后需要**重新发布一个版本**才生效 |
| 自己审核入口找不到 | 飞书消息里搜「开发者小助手」，审核通知在里面；或登录[管理后台](https://feishu.cn/admin) → 应用管理 |
| 别人私聊机器人也能触发 | 可用范围没限制，回第 5 步改成"仅自己" |

更多细节见 [飞书开放平台文档](https://open.feishu.cn/document/)。
