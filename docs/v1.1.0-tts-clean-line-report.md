# Firefly-Agent — V1.1.0 TTS Clean Line Report

## 1. Executive Summary
The TTS pipeline in Firefly-Agent has been finalized into a single, clean, robust runtime contract. All legacy/obsolete engine implementations (`edge`, `custom-cloud`, `minimax`, `mimo`, `mossland`), generic V4 references, and hardcoded absolute paths have been eradicated from product code and repository templates.

## 3. Inventory Cleanup & Eradication Matrix

### 3.1 Deleted Engine Implementations & Files
- `src/main/runtime/tts/engines/custom-cloud-engine.ts` -> **DELETED**
- `src/main/runtime/tts/engines/minimax-engine.ts` -> **DELETED**

### 3.2 Product Code & Schema Refactoring
- **`src/shared/tts-types.ts`**:
  - `TtsEngine` narrowed strictly to `"off" | "gptsovits"`.
  - Removed `CustomCloudTtsConfig`, `MinimaxTtsConfig`, `MimoTtsConfig`, `MosslandTtsConfig`.
  - Added `VoiceProfile` interface and `FIREFLY_VOICE_PROFILE` constant (`firefly-v2proplus`).
  - Removed machine-specific absolute path defaults (`E:\...`).
- **`src/main/runtime/tts/tts-dispatcher.ts`**:
  - Dispatches only to `synthesizeGptsovits` when `engine === "gptsovits"`.
  - Removed multi-engine switch branches.
  - Standardized `[TTS Trace]` logging (`request`, `dispatch`, `engine=gptsovits`, `synthesis-success`, `synthesis-error`).
- **`src/main/runtime/tts/tts-ipc.ts` & `src/settings/settings-manager.ts`**:
  - `VALID_TTS_ENGINES` restricted to `new Set(["off", "gptsovits"])`.
  - Legacy configuration containing `"edge"`, `"custom-cloud"`, `"minimax"`, etc., is automatically migrated to `"gptsovits"` on load, while strictly preserving existing GPT-SoVITS user parameters.
- **`src/renderer/ui/components/SettingsView.tsx`**:
  - Voice engine selector cleanly restricted to:
    1. `流萤标准语音 · GPT-SoVITS V2ProPlus (127.0.0.1:9880)`
    2. `静音 / 关闭语音合成`
- **`src/settings/settings.example.json`**:
  - Purged obsolete engine blocks; provides clean generic template.
- **`src/renderer/public/voice_reference/reference_manifest.json`**:
  - Changed absolute path to canonical relative `samples/sample_1.wav`.

## 4. Decoupling & Playback Lifecycle

### 4.1 Playback UI
- **Normal / Playing / After**: `🔈 播放语音` (No `🔊 朗读中...`).
- **Error**: `⚠️ 播放失败`.

### 4.2 Live2D Lifecycle Isolation
- **TTS Success**: `speaking=true` -> `mouthSync.start()`.
- **Playback Finish**: `speaking=false` -> `mouthSync.stop()`.
- **TTS Failure**: `speaking=false` -> `mouthSync.stop()`. Real error captured with honest `[TTS Trace]` logs.
- **Expression Non-Interference**: TTS never alters or overrides the character's Live2D base expression.
- **Idle Baseline**: `expression00` + `Idle/0` remains the single persistent standby baseline.
