ASR 设置

在输入框点击语音转文字后才使用麦克风。音频发往所选服务商，识别结果仅填入草稿，不自动发送。每次最长约 110 秒。

Mossland

停止录音后上传音频并返回完整文字；停止前取消不会上传。

阿里云

识别语言以阿里云项目配置为准。

录音期间持续向阿里云发送音频；取消后停止发送，但无法撤回已发送部分。

此配置也用于已启用渠道的语音消息识别；关闭不删除已保存凭据。

连接手机

把 Firefly 接到微信、飞书等聊天平台。在外部渠道里的每个用户会拥有独立的对话上下文与记忆。

微信

未启用

通过腾讯 iLink Bot API（个人微信官方接入通道）直连微信，无须外部网关。 点击"扫码登录"在 Firefly 内弹出二维码窗口，扫描后自动连接。

扫码登录微信

请用微信扫描二维码完成登录

飞书

未启用

通过飞书官方 SDK 的长连接 WebSocket接收消息（无需公网/内网穿透）。 在 飞书开放平台 创建自建应用 → 开启"机器人"能力 → 填入下方 App ID/Secret → 启用即可。

QQ（NapCat / OneBot 11）

未启用

Firefly 在 Windows 监听反向 WebSocket，NapCat 作为 WebSocket Client 连接。 群聊仅响应白名单群中的 @；群聊共享个人记忆但强制禁用工具，请只添加可信群。

QQ 机器人（官方开放平台）

未启用

在 q.qq.com 创建机器人后填入 AppID / AppSecret。官方协议零封号风险，但仅支持被动回复 （单聊 60 分钟内 4 条、群聊 5 分钟内 5 条，无主动消息）；群聊仅响应白名单群中的 @。 新机器人默认沙箱模式，需先在开放平台添加测试用户。

查驾车/步行/骑行/公交的路线规划和预计时间。需要高德 Key（ 注册 Key，与天气查询共用）。

高德开放平台 → 控制台 → 应用管理 → 创建「Web服务」类型 Key。与天气查询共用同一个 Key。
